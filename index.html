I fine-tuned a 3B model to call tools.


xLAM-AETHER-v1 is the engine for Project AETHER, an agent that turns a goal into structured JSON tool calls. Fine-tuned from Salesforce xLAM-2-3b with QLoRA on 5,000 multi-turn function-calling trajectories, then quantized to run on a laptop.




3.09Bbase parameters


1.93 GBQ4_K_M GGUF


32ktoken context


1.1 stool call on a T4




Trained for one epoch on a free Colab T4 with Unsloth. Non-commercial licence (inherited from the base model). On CPU the prefill is slow, about 250 s per prompt, and it handles single tool calls, not parallel ones.
